## 3. 空内容编辑命中区域

建议规则：

- 可编辑单元格高度至少 24px；空内容最小宽度建议 48px，字号变大后可用 `em` 扩展。
- 不只增大编辑框弹出后的尺寸，而是增大弹出前按钮本身的命中区域。
- 空值区域可显示低对比度的“空字符串”，空属性名可显示“空属性名”；这些仅是界面提示，不写入 JSON。
- 判断空内容基于数据，不根据显示文本是否为空判断，因为空属性名当前已经可能显示为 `""`。
- 通过内边距与最小宽度实现，不使用覆盖邻近图标的透明绝对定位层。
- 保留长文本截断、可见焦点、禁用态，以及窄窗口下的滚动或截断策略。

验收：对 `{"":"","name":"","spaces":"   ","items":[""]}` 中适用的 key/value，在新增命中区域边缘单击也能打开正确输入框；不会误触另一字段、展开箭头或手柄。编辑提交、取消、中文输入和 Tab 切换继续正常。

## 4. 左键菜单、右键拖动

### 4.1 操作规则

| 区域             | 左键                                       | 右键                                   |
| ---------------- | ------------------------------------------ | -------------------------------------- |
| 行首节点手柄     | 单击选择节点并打开菜单；按住移动不拖动节点 | 按住并移动超过阈值后开始拖动；松开提交 |
| key/value 单元格 | 保持单击编辑                               | 不发起节点拖动                         |
| 展开箭头         | 保持展开/折叠                              | 不发起节点拖动                         |
| 行内其他空白     | 保持选择                                   | 不发起节点拖动                         |

右键短按手柄不移动节点，也不弹出浏览器原生菜单。只在相关手柄与拖动会话内抑制原生菜单，不全局改变代码编辑器的右键行为。根节点仍可打开菜单，但不能拖动；只读、解析未完成、过期树等状态沿用现有限制。

### 4.2 技术路径与风险

现有手柄通过 react-arborist 接入拖动，并使用原生 `dragstart/dragover/drop/dragend` 处理边缘滚动。不能仅把菜单从 `onContextMenu` 移到 `onClick` 就认为需求完成，也不能预设原生 HTML5 拖放会因按钮改为右键而照常工作。

先做最小可行性验证：在当前 Electron 中以真实右键按下、移动、松开，检查现有拖动后端能否可靠启动与结束。若不能，采用局部 Pointer Events 拖动适配层，不靠合成 HTML5 事件模拟实际用户输入。

适配层需要：

1. 使用右键 `pointerdown` 建立候选会话，移动约 5px 后进入拖动；左键永远不启动移动。
2. 保留指针捕获或等价的全程监听；捕获期间按坐标判定目标，不能直接依赖被捕获的事件 target。
3. 依据虚拟列表当前行和坐标，解析目标父节点及插入位置；复用 `canDrop`、移动索引计算与命令提交路径。
4. 保留同级排序、跨父节点移动、放入容器、禁止循环和重复属性名等已有规则。
5. 复用或适配拖动指示线、容器高亮、无效目标提示、边缘自动滚动和落位反馈；滚动后重新命中目标。
6. 松开时提交一次现有移动命令；没有有效移动则不产生历史记录。撤销、重做继续恢复节点身份。
7. Esc、`pointercancel`、捕获丢失、窗口失焦、组件卸载、切换文件或树 revision 变化时取消并清理监听、动画帧和提示。
8. 移除或禁用手柄原有左键拖动连接，避免两条输入链路同时运行。

保留 Enter/Space、Shift+F10 和菜单键打开菜单。已有菜单中的“移动”对话框继续作为无需鼠标拖动的路径。更新手柄提示为“左键打开菜单；按住右键拖动”。

验收必须包含真实鼠标右键事件，不能只派发合成 `DragEvent`。现有 `tests/e2e/context-menu.spec.ts` 明确验证左键原生拖动，需要随新规则更新。

## 5. 悬停展开子菜单

- 指针进入启用的“类型”“更多”等带子菜单项时自动展开，建议短延迟约 120ms，避免快速扫过时频繁闪动。
- 从主项穿过当前约 4px 的间隙进入子菜单时保持打开；建议使用可取消的关闭延迟约 200ms，并将父项和对应子菜单视作同一悬停区域。
- 进入另一个带子菜单项切换展开项；进入普通菜单项后关闭旧子菜单；禁用项不展开。
- 只展开当前一组子菜单，离开整个菜单区域后关闭子菜单；主菜单仍按外部点击、Esc、执行命令等既有规则关闭。
- 鼠标悬停不强制抢走键盘焦点。当前子菜单挂载后会聚焦首项，需要按打开来源区分处理。
- 保留点击、Enter/Space 与方向右键展开，方向左键返回父项；维护 `aria-expanded` 和焦点恢复。
- 沿用现有屏幕边缘翻转、位置限制和减少动态效果偏好；计时器在关闭、切换节点和卸载时清理。

验收覆盖悬停、快速切换、跨间隙、禁用项、窄窗口左右翻转、键盘操作与菜单外点击。

## 6. 独立字号设置

### 6.1 用户界面与保存规则

沿用现有紧凑桌面工具风格，只新增组件，不改页面布局或配色，不需要图片素材。

工具栏新增带可访问名称和提示的设置图标按钮，打开应用内模态设置对话框。对话框提供：

- “树文本大小”：默认 12px。
- “代码文本大小”：默认 14px。
- 建议均支持 10–24px、步长 1px，通过有标签的数字输入框或下拉框设置。
- “恢复默认”和“关闭”；采用即时应用与保存，Esc 和关闭按钮结束设置，不回滚已生效值。

这些范围与保存方式属于建议默认值。字号属于应用偏好，跨文件及重启保留，不写入 JSON、不标记文件为已修改、不加入文档撤销历史。存储不可用时仍允许本次会话调整。

设置窗口支持焦点限制、Esc 关闭并恢复入口焦点；小窗口下内容可滚动。输入暂时为空或非法时保留上次有效字号，并显示明确的有效范围，不将无效值应用到编辑器。

### 6.2 实现细节

1. 新增独立的版本化编辑器设置模块，例如 `editor-preferences.ts`，使用独立 localStorage key；读取时检查版本、类型、有限数值、整数及范围，异常项回退默认值。
2. 树通过 CSS 变量应用字号，并同步计算 react-arborist 的 `rowHeight`。建议 `max(30, ceil(fontSize * 1.5 + 8))`，同时调整编辑单元格高度，避免字体变大被裁切。
3. 行内输入浮层使用 portal，不能仅依赖树面板 CSS 继承；需显式传入字号或设置浮层变量，并在字号变化后重新计算位置。
4. 树行高变化后检查虚拟滚动、选中行可见性、拖动坐标与边缘滚动。拖动时冻结或取消当前会话后再应用布局变化，避免错误落点。
5. 为 `EditorView` 提供窄接口更新字号，在内部更新现有 Monaco 实例选项；初次创建也读取设置。不要为调字号重建文本模型或整个编辑器。
6. 设置状态由工作区统一持有；新建、打开文件和交换双栏后仍保持生效。
7. 设置仅影响树内容、树行内输入和代码编辑区；工具栏、节点菜单和设置窗口自身字号保持界面规范。

## 10. 阶段 2 实施与验证记录

### 10.1 实际行为

- 仅行首手柄的左键单击打开节点菜单；Enter、Space、Shift+F10 和菜单键入口保持可用。
- 手柄右键按下并移动至少 5px 才启动拖动，短按不移动也不打开节点菜单。左键按住移动不再拖动节点。
- 目标行上缘/下缘用于同级插入；容器行中部用于添加到容器末尾。有效位置显示插入线或容器高亮，无效目标显示边框和提示，提示跟随指针并限制在视口内。
- 复用 `TreePresentationStore.canDrop/move/drop` 与既有移动命令，保留循环、重复属性名、数组元素移入对象需填写名称等校验。相同位置不提交命令；有效移动一次撤销、重做恢复节点身份。
- 指针捕获在树视口上，源行因虚拟滚动卸载后仍可继续拖动；保留边缘自动滚动，并按当前坐标重新判定落点。
- 松开右键、Esc、移出区域后松开、pointercancel、丢失捕获、窗口失焦、窗口尺寸变化、树版本或文档切换、组件卸载时，清理会话、帧循环及提示；无效和取消操作不修改 JSON。
- 根节点、过期树和只读树不能拖动。行内草稿尚未结束时不启动拖动，先提交或取消编辑后可操作手柄。
- key/value 左键编辑、展开按钮、菜单中的“移动到…”保留；手柄外的代码编辑器右键事件不被拦截。

### 10.2 实现与验证依据

先以真实右键按下、移动、松开验证原有实现，确认 HTML5 后端未启动右键拖动，因此采用 `use-handle-drag.ts` 局部 Pointer Events 实现。移除手柄原有拖动连接、原生拖放滚动监听及不再使用的 `DropCursor.tsx`，关闭 Arborist 原生拖动与投放，避免左右键并行触发两条链路。

自定义拖动按当前坐标命中完整虚拟行，包括行内容下方的空白，不依赖捕获后的 event target。命令提交前再次检查可编辑状态与版本；成功后打开目标容器并沿用既有落位反馈。

共享 E2E 菜单辅助方法、输入模式测试、边界验收测试与 `tools/run-tree-probe.mjs` 已迁移到左键菜单。原合成 DragEvent 测试已改为真实右键鼠标输入；增加取消、无效目标、只读、版本变化、虚拟滚动与缩放用例。
